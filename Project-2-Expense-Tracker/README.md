# 💰 Expense Tracker

A beginner-friendly Python Expense Tracker developed as
Project 2 of my DecodeLabs Python Programming Internship.

## Features

- Add expenses with names and amounts
- View all recorded expenses
- Calculate total spending
- Input validation
- Simple command-line interface

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Exception Handling

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run:

python expense_tracker.py

1. Add Expense
2. View Expenses
3. View Total
4. Exit
