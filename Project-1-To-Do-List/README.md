# Project 1 - To-Do List

## Overview

This project is a simple command-line To-Do List application developed in Python as part of my DecodeLabs Python Programming Internship.

The application allows users to add, view, and delete tasks through an interactive menu.

## Features

- Add new tasks
- View all tasks
- Delete tasks
- Input validation
- Interactive command-line menu
- Continuous operation until the user chooses to exit

## Concepts Used

- Python Lists
- `append()`
- `pop()`
- `input()`
- `print()`
- `if/elif/else`
- `while` loop
- `for` loop
- Functions
- Basic exception handling

## IPO Model

### Input
The user selects an option from the menu and enters task information.

### Process
The program stores tasks in a Python list and performs the operation selected by the user.

### Output
The program displays tasks, confirmation messages, and error messages.
